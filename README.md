# 🌍 Pollution Analytics Dashboard

An interactive data visualization dashboard for exploring air, water, and land pollution trends across cities. Built with Python, Streamlit, Pandas, and Plotly, the project combines synthetic pollution data generation with interactive analytics to make environmental data easier to understand.

##  Project Overview

Pollution affects environmental quality and public health. Understanding how pollution indicators change over time can help users identify trends, compare locations, and explore relationships between different environmental factors.

The **Pollution Analytics Dashboard** provides an interactive interface for generating, filtering, analyzing, and visualizing pollution data across a selected time period.

The project also supports exporting data to CSV for further analysis in Microsoft Power BI.

> **Note:** The dataset generated by this project is synthetic and intended for educational, analytical, and demonstration purposes. It should not be treated as real-world environmental monitoring data.

##  Features

- **Synthetic Data Generation:** Generate pollution records for a selected city and time period using the configured language-model integration.
- **Interactive Dashboard:** Explore pollution data through an easy-to-use Streamlit interface.
- **Air Quality Analysis:** Visualize indicators such as PM2.5, PM10, NO₂, SO₂, CO, O₃, and AQI.
- **Time-Series Visualization:** Track changes in pollution indicators over time.
- **City Comparison:** Explore and compare available locations in the dataset.
- **Statistical Analysis:** Examine summary statistics, averages, and relationships between pollution indicators.
- **Interactive Filtering:** Filter data by date, location, and selected pollution metrics, where supported by the dashboard.
- **CSV Export:** Export data for further analysis in Microsoft Power BI or spreadsheet applications.
- **Environmental Insights:** Use charts and summary statistics to explore potential patterns in the generated dataset.

##  Pollution Indicators

The project works with the following indicators, depending on the generated dataset:

| Indicator | Description |
|---|---|
| PM2.5 | Fine particulate matter |
| PM10 | Particulate matter with a diameter of up to 10 micrometres |
| NO₂ | Nitrogen dioxide |
| SO₂ | Sulfur dioxide |
| CO | Carbon monoxide |
| O₃ | Ozone |
| AQI | Air Quality Index |
| Water Pollution | Synthetic water pollution indicator |
| Land Pollution | Synthetic land pollution indicator |

The units and interpretation of synthetic values depend on the data-generation logic. They should not be assumed to follow official monitoring standards unless explicitly validated.

##  Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/varenyaxprasad/Pollution_Analysis.git
cd Pollution_Analysis
```

### 2. Create a virtual environment

```bash
python3 -m venv .venv
```

Activate it on macOS or Linux:

```bash
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

Install the libraries required by the project:

```bash
python -m pip install streamlit pandas plotly python-dotenv langchain-groq
```

If the project uses additional packages or a `requirements.txt` file, install those dependencies as well.

### 4. Configure the language-model API

If data generation requires an API key, create a local `.env` file in the project root and add the credential using the environment-variable name expected by `src/datafetching.py`.

For example:

```text
GROQ_API_KEY=your_api_key_here
```

Make sure the code reads the same variable name. Never commit your real API key to GitHub.

### 5. Run the application

From the repository root:

```bash
python -m streamlit run src/app.py
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:8501
```

**Important:** If your terminal is already inside the `src/` directory, run:

```bash
python -m streamlit run app.py
```

##  How to Use the Dashboard

1. Launch the Streamlit application.
2. Enter the city or location you want to analyze.
3. Select the number of months for data generation.
4. Generate the synthetic pollution dataset.
5. Explore the available charts and summary statistics.
6. Adjust the date range, city, or pollution-metric filters where available.
7. Download the dataset as a CSV file for additional analysis.

The exact number of records depends on the date range, generation logic, and successful completion of the data-generation process.

## 📈 Visualizations and Analysis

The dashboard is designed to support exploration of:

- AQI trends over time.
- PM2.5 and PM10 variations.
- Comparisons between pollutant levels.
- Relationships between PM2.5 and AQI.
- Correlations among numerical pollution indicators.
- Water and land pollution trends.
- Summary statistics and key metrics.

Available charts depend on the current implementation and the columns present in the dataset.

##  Microsoft Power BI Integration

The generated dataset can be exported and analyzed using Microsoft Power BI.

1. Generate the pollution data in the dashboard.
2. Download the dataset as a CSV file.
3. Open Power BI Desktop or the Power BI service.
4. Import the downloaded CSV.
5. Verify the column data types, especially dates and numerical pollution indicators.
6. Create additional reports, charts, KPI cards, and location comparisons.

This workflow lets the project combine Python-based data generation and exploration with Power BI reporting.

##  Data and Security

- Generated records are synthetic and are not verified measurements from environmental monitoring stations.
- API credentials should be stored locally in `.env`.
- Exclude `.env`, `.venv/`, Python cache files, and other local secrets from version control.
- Generated datasets can be kept locally or shared separately when appropriate.
